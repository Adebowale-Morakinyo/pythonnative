# Navigation

The declarative navigation API: a single
[`NavigationContainer`][pythonnative.NavigationContainer] holds one or
more navigators (stack, tab, or drawer), and any descendant function
component can navigate via
[`use_navigation`][pythonnative.use_navigation] or read its current
route with [`use_route`][pythonnative.use_route].

::: pythonnative.navigation
    options:
      show_root_heading: false
      show_root_toc_entry: false
      members_order: source
      filters: ["!^_"]
